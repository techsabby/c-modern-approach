# What is a stack? 

- A stack is an abstract data structure that can be created in most languages 

- It can be visualized as a stack of plates:
    
    - You can only take a plate away from the top 
    - You can only add a plate to the top 
    - If you want to add a plate 3 from the top you have to remove 3 plates from the top first 

# Lessons from this program 

The purpose of this excerise is to practice: 

    - External variables 
    - Stack data structure 

# Implementation in C 

- The stack can be implemented in C using an array
- The top variable is used to keep track of the size of the stack
    - set to 0 means the stack is empty 
    - set to STACK_SIZE means the stack is full
